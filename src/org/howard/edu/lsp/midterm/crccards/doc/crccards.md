Library collaborates with Book, but not vice versa, because the implementation of Library depends on Book while the opposite is not true (i.e., Library requires Book objects to fulfill its responsibilities, while Book can exist independently). According to the CRC cards, Book is responsible for maintaining its own information, availability, and borrowing/returning validation, whereas Library is responsible for managing the collection of books and coordinating those operations. The three-book borrowing limit is enforced by Library because it requires knowledge of the borrowing status of multiple books within the collection, rather than the state of any individual Book. Assigning this responsibility to Library maintains a clear separation of responsibilities and prevents Book from needing knowledge of other books or the Library itself.
